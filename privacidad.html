2. Uso de los Servicios de API de YouTube

Esta aplicación usa los Servicios de API de YouTube (YouTube Data API, YouTube Analytics API y YouTube Reporting API). Al usarla, usted acepta las Condiciones del Servicio de YouTube. El tratamiento de datos por parte de Google se rige por la Política de Privacidad de Google.

3. Qué datos se consultan

Con el permiso que el dueño otorga mediante OAuth de Google, la aplicación accede a:

  • datos de sus propios canales: nombre, identificador, listas de reproducción y videos;
  • metadatos de sus videos: títulos, descripciones, etiquetas, miniaturas, subtítulos y estado de publicación;
  • estadísticas de sus canales y videos: vistas, impresiones, porcentaje de clics, retención, tiempo de reproducción, suscriptores y fuentes de tráfico, y, cuando existan, ingresos;
  • comentarios públicos en sus videos, para leerlos, responderlos o moderarlos.

La aplicación no accede a cuentas de otras personas ni recoge datos de los espectadores más allá de los datos agregados que YouTube Analytics entrega y del texto público de los comentarios.

4. Para qué se usan

Solo para que el dueño administre sus propios canales: analizar el rendimiento de sus videos, editar la información de sus videos y subir sus videos. Los datos no se venden, no se usan para publicidad y no se ceden a terceros.

5. Dónde se guardan y por cuánto tiempo

Las credenciales de acceso (token de OAuth) y las estadísticas descargadas se guardan en la computadora del dueño. Las estadísticas se conservan mientras sean útiles para comparar el rendimiento de los videos. Los datos obtenidos de los Servicios de API de YouTube que no sean estadísticas se actualizan o eliminan dentro de los 30 días, según exigen las políticas de YouTube.

6. Uso limitado

El uso y la transferencia de la información recibida de las APIs de Google cumplen la Política de Datos del Usuario de los Servicios de las APIs de Google, incluidos los requisitos de uso limitado.

7. Cómo retirar el permiso

El acceso se puede revocar en cualquier momento desde la página de seguridad de la cuenta de Google: myaccount.google.com/permissions. Al revocarlo, el dueño puede pedir que se borren los datos guardados escribiendo al correo de contacto.

8. Cookies

Este sitio no usa cookies ni herramientas de seguimiento. La aplicación no guarda ni lee cookies en los dispositivos de los usuarios.

9. Cambios

Cualquier cambio en esta política se publica en esta página con su fecha.

English summary

This application uses YouTube API Services. By using it you agree to the YouTube Terms of Service; see also the Google Privacy Policy. With the owner’s OAuth consent, it accesses only the owner’s own channels: channel and video metadata, analytics (views, impressions, CTR, retention, watch time, subscribers, traffic sources and, where available, revenue), and public comments on the owner’s videos. Data is used solely so the owner can manage his own channels; it is not sold, used for advertising or shared with third parties. Tokens and downloaded statistics are stored on the owner’s computer; non-statistical YouTube API data is refreshed or deleted within 30 days. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. No cookies are used. Contact: montillapotentiniyoutube@gmail.com
